# Myjupyter Conm

## How do I install these formulae?

`brew install myjupyter/conm/<formula>`

Or `brew tap myjupyter/conm` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "myjupyter/conm"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
